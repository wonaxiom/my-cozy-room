# 그림 정리 스크립트

GPT에서 받은 그림을 게임용 도트(`hero-art.js`)로 만드는 데 쓴 스크립트입니다. 경로는 작업할 때의 임시 폴더 기준이라, 다시 쓸 때는 파일 위치를 맞춰야 합니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `prep.py` | 배경을 지우고 그림을 칸별로 나눔 |
| 2 | `pix_base.py` | 기본형: 머리 폭이 모든 칸에서 27픽셀이 되게 도트로 줄임 |
| 2 | `pix.py` | 머리 모양: 정해진 크기(7.3배)로 도트로 줄임 |
| 3 | `fit.py` | 머리 모양을 민머리 기본형 위 제자리에 맞춤 |
| 4 | `build5.py`, `make.py` | 동작마다 머리 위치를 찾아 머리를 얹고, 부위(머리, 피부, 다리, 상의, 하의, 눈)를 나눔 |
| 5 | `emit.py` | `hero-art.js`로 저장 |

## 모자와 머리 장식

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `acc2.py` | 칸마다 그려진 머리 윤곽선을 머리핀 칸의 윤곽선과 맞춰 위치를 찾음 |
| 2 | `acc3.py` | 윤곽선을 지우고 장식만 도트로 줄임 (위치는 민머리 머리 왼쪽 위 기준) |
| 3 | `emitacc.py` | `acc-art.js`로 저장 |

## 새 장신구 (2026-11: 머리 6종, 얼굴 3종, 목도리)

원본: `art-src/acc/gpt-acc2.webp`(머리), `art-src/acc/gpt-face.webp`(얼굴), `art-src/outfit/scarf_male.webp`·`scarf_female.webp`(목도리)

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `acc_new.py new` | 머리 장식: 예전 시트 머리핀 칸의 머리 윤곽선으로 위치를 찾고 도트로 줄임 (`old`로 돌리면 예전 장식이 그대로 나오는지 확인) |
| 2 | `acc_face.py` | 얼굴 장식: 민머리 모형 위 장식 색만 골라, 칸마다 덮인 비율로 도트를 정함 (가는 안경테도 남게) |
| 3 | `scarf.py` | 목도리: 칸마다 목 둘레에 닿은 회색 덩어리만 골라 머리 왼쪽 위 기준으로 저장 |
| 4 | `emitacc2.py` | 누운 그림용 장식(`acc_lie.py`)을 만들고, 예전 장식은 둔 채 `acc-art.js`에 더함 |

- 1번 뒤에 장식 아래로 2칸 이상 떨어진 진한 칸(남은 기준선)을 지우고, 2번 뒤에 안경테를 한 가지 금색으로 칠했습니다.
- 여자 목도리 시트는 목도리와 셔츠 색이 비슷해서 골라내기 어려워, 남자 시트에서 고른 목도리를 남녀 모두에 씁니다. (머리 기준으로 붙여서 맞음)

## 크리스마스 세트 (2026-11: 산타 수염, 크리스마스 목도리, 산타 옷)

원본: `art-src/acc/gpt-beard.webp`, `art-src/outfit/xmas_scarf_male.webp`, `art-src/outfit/santa_female.webp`·`santa_male.webp`

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `acc_beard.py` | 산타 수염: 흰 수염과 둘레 외곽선만 골라 도트로 줄임 |
| 2 | `cells.py` | 시트를 칸으로 나눠 도트로 줄이는 공통 도구 (바깥과 이어진 흰색만 배경으로 봐서 흰 털이 남음). 도트 크기는 시트마다 머리 폭(27칸)으로 잼 |
| 3 | `xscarf_match.py` → `xscarf.py` | 크리스마스 목도리: 30칸 중 걷기 칸을 몸 모양으로 골라 28가지 동작에 맞추고, 빨간 목도리와 흰 방울만 고름 |
| 3-1 | `xscarf_stripe.py` | 크리스마스 목도리의 빨간 칸에 2칸 간격 사선으로 흰 줄무늬를 넣음 |
| 4 | `santa.py` | 산타 옷: 피부·회색 반바지를 뺀 빨강·흰 털·금색 버클과 벨트를 칸마다 고름 |
| 5 | `emit_xmas.py` | `acc-art.js`에 더함 (색은 그림 그대로) |

- 시트마다 GPT가 캐릭터를 조금씩 다른 크기로 그립니다 (크리스마스 목도리 시트는 한 줄에 8칸이라 12% 작음). 도트 크기를 고정값으로 두면 장식이 작아지고 위로 올라가므로, 꼭 머리 폭으로 재서 맞춥니다.
