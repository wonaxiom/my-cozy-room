# 그림 정리 스크립트

GPT에서 받은 그림을 게임용 도트(`hero-art.js`)로 만드는 데 쓴 스크립트입니다. 경로는 작업할 때의 임시 폴더 기준이라, 다시 쓸 때는 파일 위치를 맞춰야 합니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `prep.py` | 배경을 지우고 그림을 칸별로 나눔 |
| 2 | `pix_base.py` | 기본형: 머리 폭이 모든 칸에서 27픽셀이 되게 도트로 줄임 |
| 2 | `pix.py` | 머리 모양: 정해진 크기(7.3배)로 도트로 줄임 |
| 3 | `fit.py` | 머리 모양을 민머리 기본형 위 제자리에 맞춤 |
| 4 | `build5.py`, `make.py` | 동작마다 머리 위치를 찾아 머리를 얹고, 부위(머리, 피부, 다리, 상의, 하의, 눈)를 나눔 |
| 5 | `emit.py` | `hero-art.js`로 저장 |
