## 공통 구성

지금 선반 장식(평소, 12월)과 같은 자리에 들어가도록, 배경마다 아래 그림을 한 장에 받습니다.

| 자리 | 그림 | 크기 (도트, 기존 그림 기준) |
|---|---|---|
| 왼쪽 무리 | 등불(모든 배경 공통, 새로 그리지 않음) + 작은 소품 2개 | 소품 각각 약 35×30 ~ 43×42 |
| 오른쪽 무리 | 잠든 동물 2칸(숨 들이쉼·내쉼) + 키 큰 소품 1개 | 동물 약 50×32, 키 큰 소품 약 40×50 |
| 선반 띠 | 이음매 없이 가로로 반복되는 선반 (필요한 배경만) | 약 122×13 (위에 쌓인 것이 있으면 높이 16까지) |
| 하늘 | 천천히 떨어지는 작은 조각 2종 (벚꽃·단풍만) | 약 9×9, 15×16 |

- 첨부 1번(평소)과 2번(12월)은 지금 게임에 들어 있는 선반 장식입니다. 시점, 도트 크기, 색감을 이 그림에 맞춥니다.
- 동물 두 칸은 겹쳐서 번갈아 보여 주므로, 위치와 크기가 같고 몸통만 1~2도트 차이 나게 받습니다.
- 선반 띠는 왼쪽 끝과 오른쪽 끝이 이어지게 받아야 반복했을 때 이음매가 보이지 않습니다.

> 요청 1~5는 게임에 넣었습니다 (2026-11-21). 원본은 `art-src/side_sakura.webp`, `side_wood.webp`, `side_dog.webp`, `side_sea.webp`, `side_autumn.webp`이고, 정리는 `art-src/tools/side_theme.py`로 했습니다.
> 요청 6·7도 게임에 넣었습니다 (2026-11-21, 원본 `art-src/side_dogs.webp`, `side_dogs_event.webp`). 요청 7 시트는 크기가 달라 피치 7.85로 줄여 다른 강아지와 크기를 맞췄습니다.

## 요청 1. 벚꽃

```
첨부한 1번, 2번 그림은 지금 게임에 있는 선반 장식이에요. 같은 시점, 도트 크기, 분위기로 '벚꽃' 선반 장식을 한 장에 그려 주세요.
- 1줄: 벚꽃 가지를 꽂은 작은 하얀 화병, 벚꽃 경단 3색 꼬치를 올린 작은 접시, 잠든 고양이 2칸
- 2줄: 작은 벚나무 화분(분홍 꽃이 핀 둥근 나무), 떨어지는 벚꽃잎 작은 것·큰 것 2칸, 선반 띠 1칸
- 고양이: 1번 그림의 고양이와 같은 크기·자세, 방석 위에서 잠듦, 머리에 벚꽃잎 하나. 왼쪽 칸은 숨 들이쉰 모습, 오른쪽 칸은 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 선반 띠: 1번 그림의 선반 띠와 같은 높이, 위에 벚꽃잎이 드문드문 흩어짐, 왼쪽 끝과 오른쪽 끝이 이어지게
- 색: 연한 분홍과 크림색 위주, 너무 진한 분홍은 쓰지 않음
```

## 요청 2. 나무

```
첨부한 1번, 2번 그림은 지금 게임에 있는 선반 장식이에요. 같은 시점, 도트 크기, 분위기로 '나무(숲)' 선반 장식을 한 장에 그려 주세요.
- 1줄: 작은 버섯 두 개가 난 이끼 낀 그루터기, 솔방울과 도토리를 담은 작은 바구니, 잠든 고양이 2칸
- 2줄: 작은 분재 나무 화분(초록 잎, 굽은 줄기), 선반 띠 1칸
- 고양이: 1번 그림의 고양이와 같은 크기·자세, 방석 대신 동그랗게 자른 통나무 위에서 잠듦. 왼쪽 칸은 숨 들이쉰 모습, 오른쪽 칸은 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 선반 띠: 1번 그림의 선반 띠와 같은 높이, 나무껍질이 보이는 통나무 선반, 군데군데 작은 이끼, 왼쪽 끝과 오른쪽 끝이 이어지게
- 색: 따뜻한 갈색과 차분한 초록 위주
```

## 요청 3. 강아지

```
첨부한 1번, 2번 그림은 지금 게임에 있는 선반 장식이에요. 같은 시점, 도트 크기, 분위기로 '강아지' 선반 장식을 한 장에 그려 주세요.
- 1줄: 뼈다귀 모양 간식이 담긴 강아지 밥그릇, 테니스공과 작은 뼈다귀 장난감, 잠든 강아지 2칸
- 2줄: 지붕이 있는 작은 강아지 집(빨간 지붕, 크림색 벽), 선반 띠 없음
- 강아지: 1번 그림의 고양이와 같은 크기, 갈색과 흰색 털에 귀가 처진 강아지가 방석 위에서 몸을 말고 잠듦. 왼쪽 칸은 숨 들이쉰 모습, 오른쪽 칸은 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 색: 크림, 연한 갈색, 포인트로 빨강 조금
```

## 요청 4. 바다

```
- 1줄: 소라 껍데기와 조개 두세 개, 코르크 마개를 한 유리병 속 작은 돛단배, 잠든 고양이 2칸
```

## 요청 5. 단풍

```
첨부한 1번, 2번 그림은 지금 게임에 있는 선반 장식이에요. 같은 시점, 도트 크기, 분위기로 '단풍' 선반 장식을 한 장에 그려 주세요.
- 1줄: 김이 나는 따뜻한 차 한 잔, 밤과 도토리가 담긴 작은 바구니, 잠든 고양이 2칸
- 2줄: 작은 단풍나무 화분(빨강·주황 잎), 떨어지는 단풍잎 2칸(빨간 잎 작은 것, 주황 잎 큰 것), 선반 띠 1칸
- 고양이: 1번 그림의 고양이와 같은 크기·자세, 방석 위에서 잠듦, 등에 단풍잎 하나. 왼쪽 칸은 숨 들이쉰 모습, 오른쪽 칸은 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 선반 띠: 2번 그림의 눈 쌓인 선반처럼 위에 낙엽이 소복이 쌓인 모습, 왼쪽 끝과 오른쪽 끝이 이어지게
- 색: 빨강, 주황, 노랑, 갈색, 채도를 조금 낮춰 차분하게
```

## 요청 6. 배경별 강아지

'내 정보 → 선반 동물'에서 강아지를 고르면 지금은 모든 배경에서 방석 위 강아지(요청 3)가 나옵니다. 배경마다 고양이처럼 어울리는 강아지를 받기 위한 요청입니다.

```
첨부한 1번 그림의 잠든 강아지를, 2~5번 그림의 고양이 자리에 들어갈 모습으로 4쌍 그려 주세요.
- 강아지는 1번 그림과 같은 생김새, 크기, 자세 (갈색과 흰색 털, 처진 귀, 몸을 말고 잠듦)
- 4칸 × 2줄, 한 줄에 2쌍씩. 각 쌍은 왼쪽 칸이 숨 들이쉰 모습, 오른쪽 칸이 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 1줄 왼쪽 쌍(벚꽃): 2번 그림의 고양이처럼 방석 위에서 잠들고 머리에 벚꽃잎 하나
- 1줄 오른쪽 쌍(나무): 3번 그림의 고양이처럼 이끼 낀 통나무 위에서 잠듦
- 2줄 왼쪽 쌍(바다): 4번 그림의 고양이처럼 접어 둔 파란 줄무늬 비치 타월 위에서 잠듦
- 2줄 오른쪽 쌍(단풍): 5번 그림의 고양이처럼 방석 위에서 잠들고 등에 단풍잎 하나
- 방석, 통나무, 타월은 2~5번 그림과 같은 모양과 크기
```

## 요청 7. 이벤트 강아지 (12월, 새해)

```
첨부한 1번 그림의 잠든 강아지를, 2번 그림(12월)과 3번 그림(새해)의 고양이 자리에 들어갈 모습으로 2쌍 그려 주세요.
- 강아지는 1번 그림과 같은 생김새, 크기, 자세 (갈색과 흰색 털, 처진 귀, 몸을 말고 잠듦)
- 4칸 × 1줄. 각 쌍은 왼쪽 칸이 숨 들이쉰 모습, 오른쪽 칸이 내쉰 모습(몸통이 1~2도트 낮음), 나머지는 똑같이
- 왼쪽 쌍(12월): 2번 그림의 고양이처럼 방석 위에서 잠들고 머리에 빨간 산타 모자
- 오른쪽 쌍(새해): 3번 그림의 고양이처럼 방석 위에서 잠들고 앞발 옆에 작은 빨간 복주머니
```

## 그림을 받은 뒤 할 일

- `art-src/`에 원본을 두고, `art-src/tools/side_theme.py`로 잘라 `img/side/`에 넣습니다.
- `side-deco.js`
  - `DECO_THEMES`에 그림 이름과 함께 한 줄 추가합니다. (예: `{ id: "sakura", name: "벚꽃", art: { left: [...], pets: { cat: "sakuraCat" }, tall: "sakuraTree", strip: "sakuraStripTile", fall: [...] } }`)
  - `SIZE`에 새 그림 크기를 넣습니다.
  - 이렇게 하면 '내 정보' 선택지와 선반(보통 화면, 세로 보기)에 저절로 나옵니다.
- 요청 6·7의 강아지
  - 이름: `sakuraDogA/B`, `woodDogA/B`, `seaDogA/B`, `autumnDogA/B`, `xdogA/B`, `nydogA/B`
  - `side-deco.js`에서 각 배경의 `pets`에 `dog: "sakuraDog"`처럼 넣습니다. (12월은 `DECO_THEMES`의 december, 새해는 `NEWYEAR_PETS`)
  - 배경에 맞춘 그림이 없으면 방석 위 강아지(`dogA/B`)가 대신 나옵니다.
