## 요청 1. 산타 수염

```
첨부한 1번 민머리 모형(앞모습, 뒷모습) 위에 산타 수염만 덧그린 그림을 그려 주세요. 2번 그림은 같은 방식으로 얼굴 장식을 그린 예시예요.
- 2칸 × 1줄: 왼쪽 칸은 오른쪽을 바라보는 3/4 모습, 오른쪽 칸은 뒷모습
- 모형의 모양, 크기, 색, 위치는 1번 그림 그대로 두고 수염만 더함
- 수염: 흰색 몽실몽실한 털, 코 아래 콧수염부터 턱 아래 목까지 덮음, 눈은 가리지 않음, 명암은 연한 회색과 아주 연한 하늘색
- 뒷모습은 귀 옆으로 살짝 삐져나온 수염 끝만 보임
```

## 요청 2. 크리스마스 목도리 (남자)

```
첨부한 1번 기본 모형 28칸 동작 시트에 크리스마스 목도리만 덧그려 주세요. 2번 그림은 같은 방식으로 목도리를 그린 예시예요.
- 칸 배치(7칸 × 4줄)와 캐릭터의 모양, 크기, 위치, 동작은 1번 그림과 똑같이 두고 목도리만 더함
- 목도리 모양은 2번 그림과 같게: 목에 두 번 감고, 한쪽 끝이 가슴 앞으로 내려옴
- 이번에는 회색이 아니라 실제 색으로: 진한 빨간 니트 목도리, 내려온 끝에 동그란 흰 솜털 방울
- 뒷모습 칸은 목 뒤로 감긴 부분, 앉기 칸도 모두 목에 감긴 모습
```

## 요청 3. 산타 옷 (여자)

```
첨부한 1번 기본 모형 28칸 동작 시트에 산타 옷을 입혀 주세요. 2번 그림은 같은 방식으로 재킷을 입힌 예시예요.
- 칸 배치(7칸 × 4줄)와 캐릭터의 모양, 크기, 위치, 동작은 1번 그림과 똑같이 두고 옷만 바꿈
- 산타 옷: 빨간 긴소매 윗옷, 엉덩이를 덮는 길이, 앞섶 가운데·밑단·소매 끝에 흰 털 테두리, 허리에 검은 벨트와 금색 버클
- 하의는 1번 그림의 회색 반바지 그대로 (게임에서 고른 하의를 씀)
- 이번에는 회색이 아니라 실제 색으로 그림
- 뒷모습 칸은 빨간 등판과 밑단의 흰 털, 검은 벨트
```
