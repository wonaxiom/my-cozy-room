## 공통 규칙 (모든 요청 맨 앞에 붙임)

```
아늑한 코지 도트 게임의 캐릭터 장식 그림을 부탁해요.
- 도트(픽셀) 그림, 안티에일리어싱(번짐, 흐린 가장자리) 없음
- 도트는 촘촘하게, 1칸이 정확히 같은 크기의 정사각형
- 배경은 진짜 투명 (체크무늬 그림 금지)
- 글자, 숫자, 바닥 그림자, 칸 테두리 넣지 않기
- 외곽선은 1도트, 진한 갈색(#3a2a24 근처), 검정은 쓰지 않음
- 명암은 부위당 2~3단계, 빛은 왼쪽 위에서 들어옴
- 부드러운 색, 낮은 대비
```

## 요청 1. 머리 장식 6종

첨부: ① `gpt-acc.webp` (형식·그림체 예시) ② `base_hair_ref.png` (머리 크기 기준)

```
첨부한 1번 그림과 똑같은 형식으로 머리 장식 시트를 그려 주세요.
- 4칸 × 3줄, 장식 하나에 2칸씩: 왼쪽 칸은 오른쪽을 바라보는 3/4 모습, 오른쪽 칸은 뒷모습
- 칸마다 위치 기준이 되는 가는 진갈색 머리 윤곽선만 그리고(1번 그림과 같은 크기와 모양), 얼굴과 몸은 그리지 않음
- 머리 크기는 2번 그림의 민머리 모형과 같게, 모든 칸의 머리 윤곽선 크기를 똑같이

순서
1줄: 산타 모자 (빨강, 아래에 흰 털 테두리, 끝의 흰 방울이 뒤쪽 아래로 처짐)
     방울 털모자 (크림색 니트, 꼭대기에 큰 털방울, 귀 위까지 덮는 길이)
2줄: 귀마개 (흰 털 동그라미 두 개를 갈색 머리띠로 이음, 3/4 모습에서는 앞쪽 귀마개가 크게 보임)
     고양이 귀 머리띠 (검정 머리띠, 뾰족한 삼각 귀 2개, 귀 안쪽은 분홍)
3줄: 토끼 귀 머리띠 (흰색 긴 귀 2개, 한쪽 귀 끝이 살짝 접힘, 귀 안쪽은 분홍)
     곰 귀 머리띠 (갈색 머리띠, 동그란 갈색 귀 2개, 귀 안쪽은 연한 베이지)
```

## 요청 2. 얼굴 장식 3종

첨부: ① `base_hair_ref.png` (민머리 모형) ② `gpt-acc.webp` (그림체 예시)

```
첨부한 1번 민머리 모형(앞모습, 뒷모습) 위에 얼굴 장식만 덧그린 시트를 그려 주세요.
- 2칸 × 3줄, 줄마다 왼쪽 칸은 오른쪽을 바라보는 3/4 모습, 오른쪽 칸은 뒷모습
- 모형의 모양, 크기, 색, 위치는 1번 그림 그대로 두고 장식만 더함 (모든 칸의 모형이 똑같아야 함)

순서
1줄: 동그란 안경 (가는 금색 테, 크고 동그란 렌즈, 렌즈는 아주 연한 하늘색)
     뒷모습은 귀에 걸린 안경다리만 보임
2줄: 볼 반창고 (보이는 쪽 볼에 살구색 반창고 하나, 가로로 붙임)
     뒷모습은 반창고가 보이지 않으므로 모형만 그림
3줄: 마스크 (흰 천 마스크, 코부터 턱까지 덮음, 가는 귀걸이 끈)
     뒷모습은 귀에 걸린 끈만 보임
```

## 요청 3. 목도리 (여자)

첨부: ① `bf-pose-sheet.png` (여자 기본 모형 28칸) ② `jacket_female.webp` (같은 방식으로 재킷을 입힌 예시)

```
첨부한 1번 기본 모형 28칸 동작 시트에 목도리만 덧그려 주세요. 2번 그림은 같은 방식으로 재킷을 입힌 예시예요.
- 칸 배치(7칸 × 4줄)와 캐릭터의 모양, 크기, 위치, 동작은 1번 그림과 똑같이 두고 목도리만 더함
- 목도리: 목에 두 번 감은 니트 목도리, 한쪽 끝이 가슴 앞으로 내려오고 끝에 짧은 술
- 색은 회색 계열 단색에 명암 2~3단계 (게임에서 색을 바꿔 칠함)
- 뒷모습 칸은 목 뒤로 감긴 부분과 늘어진 끝, 앉기·잠자기 칸도 모두 목에 감긴 모습
```

## 그림을 받은 뒤 할 일

- 머리 장식: `acc2.py` → `acc3.py` → `emitacc.py` 순서로 `acc-art.js`에 넣음
- 목도리·넥타이·앞치마: 재킷과 같은 옷 층(`outfit-art.js`)으로 넣음
- 지금은 장신구를 하나만 쓸 수 있어서, 칸을 **머리 / 얼굴 / 목**으로 나눠 함께 쓸 수 있게 바꿈 (예: 산타 모자 + 동그란 안경 + 목도리)
- 산타 모자·귀마개·방울 털모자·목도리는 11월~1월 크리스마스 기간에 상점에 보이게 할지 정함
