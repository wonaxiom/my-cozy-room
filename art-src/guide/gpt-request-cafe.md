# 카페 미니게임 GPT 요청문 (2026-11)

카페 미니게임(`cafe.js`)에서 지금 임시 글자 그림으로 그린 컵과, 버튼의 색 점으로 대신한 재료를 그림으로 바꾸기 위한 요청문입니다.
GPT 프로젝트 지침([gpt-project-instructions.md](gpt-project-instructions.md))이 들어 있다는 기준으로, 공통 규칙은 빼고 적었습니다.

| 요청 | 내용 | 첨부 그림 | 우선순위 |
|---|---|---|---|
| 1 | 음료 컵 12칸 (따뜻한 6, 아이스 6) | `art-src/guide/cafe-cup-ref.png`, `art-src/gpt-furniture-1.webp` | 먼저 |
| 2 | 재료 아이콘 6칸 | 요청 1에서 받은 그림 | 먼저 |
| 3 | 가게 늘리기 아이콘 5칸 (커피 머신 3단계, 의자, 간판) | `art-src/gpt-furniture-1.webp` | 나중 |
| 4 | 가게 안 배경 (손님 쪽) | `art-src/cafe/gpt-cups.webp`, `art-src/gpt-furniture-1.webp` | 먼저 |
| 5 | 카운터 윗면 (내 쪽) | 요청 4에서 받은 그림, `art-src/cafe/gpt-ingredients.webp` | 먼저 |
| 6 | 작은 그림 4칸 (휴지통, 쟁반, 하트, 화남 표시) | `art-src/cafe/gpt-cups.webp` | 나중 |

> 요청 1~6 모두 게임에 넣었습니다 (2026-11-22). 요청 4~6 원본은 `art-src/cafe/gpt-bg.webp`, `gpt-counter.webp`, `gpt-small.webp`입니다. 원본은 `art-src/cafe/gpt-cups.webp`, `gpt-ingredients.webp`, `gpt-upgrades.webp`이고, 정리는 `art-src/tools/cafe_proc.py`로 했습니다.

## 공통 구성

- 컵과 아이콘은 방 가구처럼 바닥에 놓지 않고 화면 버튼과 말풍선에 들어가므로, **아이소메트릭이 아니라 살짝 위에서 본 정면 모습**으로 받습니다.
- 칸 크기가 모두 같아야 잘라 쓰기 쉽습니다. 그림은 칸 가운데, 바닥선은 모든 칸에서 같은 높이로 맞춥니다.
- 그림체 기준은 GPT에서 받은 가구 시트(`gpt-furniture-1.webp`)입니다. 예전 기준 시트(`basic-*-ref.png`)는 코드로 그린 상자형 그림이고 칸마다 글자가 있어서 쓰지 않습니다.
- `cafe-cup-ref.png`는 지금 게임에 들어간 임시 컵 그림을 10배로 키운 샘플입니다. (1줄 따뜻한 컵, 2줄 아이스 컵, 칸 순서는 빈 컵, 아메리카노, 카페라떼, 바닐라 라떼, 초코 라떼, 녹차 라떼)

## 요청 1. 음료 컵

```
첨부한 1번 그림은 지금 게임에 임시로 넣은 컵(10배 확대)이고, 2번 그림은 게임에 있는 가구와 소품이에요. 1번의 칸 배치와 음료 색을 따르되, 2번과 같은 그림체와 명암으로 더 예쁘게 다시 그려 주세요.
- 정면에서 살짝 위로 본 모습 (아이소메트릭 아님), 칸 하나에 컵 하나, 칸 크기 약 24×28도트
- 1줄 (따뜻한 음료, 크림색 머그, 오른쪽에 손잡이): 빈 머그, 아메리카노, 카페라떼, 바닐라 라떼, 초코 라떼, 녹차 라떼
- 2줄 (아이스 음료, 투명한 플라스틱 컵, 빨간 빨대, 얼음 2~3조각): 빈 컵, 아메리카노, 카페라떼, 바닐라 라떼, 초코 라떼, 녹차 라떼
- 따뜻한 음료는 위로 김이 2줄 살짝 올라감 (빈 머그는 김 없음)
- 음료 색: 아메리카노 진한 갈색, 카페라떼 연한 갈색, 바닐라 라떼 크림빛 갈색, 초코 라떼 짙은 초콜릿색, 녹차 라떼 연두색
- 라떼 종류는 머그 위에 하트 모양 우유 거품을 살짝
- 같은 줄의 컵은 모양과 위치가 같고 음료만 다르게
```

## 요청 2. 재료 아이콘

```
첨부한 그림은 앞서 받은 카페 음료 컵이에요. 같은 도트 크기, 색감으로 음료 재료 아이콘을 한 줄에 그려 주세요.
- 정면에서 살짝 위로 본 모습, 칸 크기 약 20×20도트, 칸 하나에 하나
- 순서: 에스프레소(작은 샷 잔에 담긴 진한 커피), 물(투명한 물병), 우유(작은 우유 팩), 바닐라(노란 라벨 시럽 병), 초코(초코 소스 병), 녹차(녹차 가루 통)
- 작은 크기에서도 무엇인지 알아보게 모양을 단순하고 또렷하게
```

## 요청 3. 가게 늘리기 아이콘

```
첨부한 그림은 지금 게임에 있는 가구와 소품이에요. 같은 시점(아이소메트릭), 그림체, 색감으로 카페 장비를 한 줄에 그려 주세요.
- 칸 크기 약 40×40도트, 칸 하나에 하나
- 순서: 커피 머신 1단계(작은 가정용 머신), 커피 머신 2단계(조금 큰 은색 머신), 커피 머신 3단계(손잡이 2개 달린 큰 업소용 머신), 푹신한 의자(쿠션이 두툼한 카페 의자), 예쁜 간판(커피잔 그림이 있는 작은 입간판, 글자 없음)
- 커피 머신 3단계는 단계가 올라갈수록 조금씩 커지고 멋있어지게
```

## 가게 화면 구성 (요청 4~6)

영업 화면은 카운터 너머로 가게 안을 보는 그림입니다. 게임은 280 × 208 도트 화면에 아래 순서로 겹쳐 그립니다.

| 층 | 그림 | 크기 (도트) | 자리 |
|---|---|---|---|
| 1 | 가게 안 배경 (`bg`) | 280 × 120 | 맨 위 |
| 2 | 손님 (게임 캐릭터) | 키 약 70 | 가운데 x 104, 162, 220에 섬. 발은 카운터에 가려짐 |
| 3 | 카운터 윗면 (`counter`) | 280 × 92 | 위에서 116도트부터 |
| 4 | 컵, 커피 머신, 재료 병, 휴지통 (이미 받은 그림) | | 카운터 위 |

- 도트 크기는 요청 1의 컵 그림과 같게 받습니다. (컵 하나가 약 25도트 폭)
- 배경과 카운터는 정면에서 본 모습입니다. 아이소메트릭이 아닙니다.

## 요청 4. 가게 안 배경

```
첨부한 1번 그림은 이 게임의 카페 컵이고, 2번은 게임의 가구예요. 같은 그림체, 색감, 도트 크기로 '작은 동네 카페의 안쪽 벽'을 정면에서 본 배경 한 장을 그려 주세요.
- 바리스타가 카운터 뒤에서 손님 쪽을 바라보는 시점. 카운터와 사람은 그리지 않음 (게임에서 따로 그림)
- 가로:세로 = 7:3 (도트로 약 280 × 120), 화면을 꽉 채우는 배경 (투명 아님)
- 왼쪽 끝: 손님이 드나드는 나무 문 (유리 창이 달림, 폭 약 32도트)
- 벽: 크림색 벽지 위쪽, 아래 3분의 1은 나무판 벽
- 가운데 위: 글자 없는 작은 칠판 메뉴판 (컵 그림 몇 개만)
- 오른쪽 위: 창문 하나 (바깥은 맑은 하늘과 나무)
- 화분, 벽 선반, 작은 액자 같은 소품을 드문드문
- 가운데 아래쪽(문 오른쪽부터 오른쪽 끝까지, 세로 아래 절반)은 손님이 서는 자리라 소품을 두지 않고 벽만 보이게
- 따뜻한 오후 햇살 느낌, 낮은 대비
```

## 요청 5. 카운터 윗면

```
첨부한 1번 그림은 앞서 받은 카페 배경이에요. 같은 그림체, 색감, 도트 크기로 그 배경 앞에 놓일 '나무 카운터 윗면'을 그려 주세요.
- 바리스타 쪽에서 내려다본 카운터 윗면. 위쪽 가장자리는 손님 쪽 모서리(조금 진한 나무 띠)
- 가로:세로 = 3:1 (도트로 약 280 × 92), 꽉 채움 (투명 아님)
- 윗면은 밝은 원목 나뭇결, 아무것도 올려 두지 않음 (컵, 머신, 재료는 게임에서 올림)
- 맨 위 1~2도트는 손님 몸을 가리는 모서리라 또렷한 외곽선
```

## 요청 6. 작은 그림

```
첨부한 그림은 이 게임의 카페 컵이에요. 같은 그림체와 도트 크기로 작은 그림 4개를 한 줄에 그려 주세요. 칸 하나에 하나, 정면에서 본 모습.
- 휴지통: 회색 금속 페달 휴지통 (약 16 × 20도트)
- 쟁반: 컵을 올려 두는 납작한 은색 쟁반 (약 34 × 6도트)
- 하트: 손님이 기뻐할 때 머리 위에 뜨는 작은 빨간 하트 (약 9 × 8도트)
- 화남 표시: 손님이 화날 때 머리 위에 뜨는 빨간 십자 핏줄 표시 (약 9 × 9도트)
```

## 넣는 방법

- 원본은 `art-src/cafe/`에 두고, `python3 art-src/tools/cafe_proc.py`로 칸을 잘라 `img/cafe/`에 넣습니다.
- 스크립트는 흰 배경을 지우고(바깥에서 이어진 흰색만), 빈 줄과 빈 칸으로 칸을 나눈 뒤, 외곽선 두께로 잰 도트 크기(컵 9.5, 재료 13.5, 장비 10.5, 작은 그림 17.5픽셀)로 줄입니다. 배경과 카운터는 위아래 흰 여백을 잘라 낸 뒤 가로 280도트로 줄입니다. (배경 280 × 120, 카운터 280 × 85) 다시 받은 그림의 도트 크기가 다르면 `SHEETS`의 숫자를 고칩니다.
- 요청 4~6 그림은 `img/cafe/bg.png`, `counter.png`, `trash.png`, `tray.png`, `heart.png`, `angry.png`로 넣고, `cafe.js`의 `SCENE_ART`에 이름을 적으면 임시 그림 대신 쓰입니다.
- 그림 크기가 바뀌면 `cafe.js`의 `ART_SIZE`도 맞춥니다. (지금 따뜻한 컵 25×27, 아이스 컵 22×30, 재료 20×28, 장비 43×45)
