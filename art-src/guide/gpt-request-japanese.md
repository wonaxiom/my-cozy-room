GPT 프로젝트 지침([gpt-project-instructions.md](gpt-project-instructions.md))이 들어 있다는 기준으로, 공통 규칙은 빼고 적었습니다.

## 공통 기준

- 첨부 그림 `art-src/guide/jp-ref.png`는 지금 게임에 있는 일본풍 가구입니다. (족자, 액자, 코타츠, 좌탁, 방석을 6배로 키움. 족자와 액자는 오른쪽 벽에 걸린 모습)
- 시점: 아이소메트릭. 바닥선과 윗면 모서리가 **정확히 가로 2칸에 세로 1칸**씩 기울게 그립니다. (카페 가구를 받을 때 GPT가 더 완만하게 그려서 어긋난 적이 있음)
- 가구 방향: 앞면이 오른쪽 아래, 옆면이 왼쪽 아래를 봅니다.
- 벽 장식: **오른쪽 벽에 걸린 모습**으로 받습니다. 가로선이 오른쪽으로 갈수록 내려갑니다. (첨부의 족자와 같은 방향, 왼쪽 벽에 걸 때는 게임에서 뒤집음)

## 요청 1. 유카타 걸이

```
첨부한 그림은 이 게임에 있는 일본풍 가구예요. 같은 그림체, 색감, 도트 크기로 '유카타 걸이' 벽 장식을 그려 주세요.
- 벽에 거는 액자형 옷걸이: 위에 가로로 긴 나무 봉(양 끝이 살짝 튀어나옴), 봉에 유카타 한 벌이 소매를 양옆으로 펼친 채 걸려 있음
- 유카타: 남색 바탕에 흰 꽃무늬(나팔꽃), 허리에 빨간 오비(띠)
- 오른쪽 벽에 걸린 모습: 첨부한 족자와 같은 방향으로, 가로선이 오른쪽으로 갈수록 내려감 (가로 2칸에 세로 1칸)
- 크기: 약 40 × 55도트 (족자보다 조금 넓게)
- 벽은 그리지 않음, 배경 투명
- 같은 칸 크기로 오른쪽에 색만 바꾼 두 벌을 더 그려 주세요: 분홍 바탕 흰 꽃무늬 + 노란 오비, 흰 바탕 파란 물결무늬 + 남색 오비
```

받으면 `art-src/japanese/`에 원본을 두고 `img/furn/`에 넣습니다. 세 벌은 색상 변형(상점에서 색 고르기)으로 묶습니다.

> 넣었습니다 (2026-11-23). 원본 `art-src/japanese/gpt-yukata.webp`, 정리 `art-src/tools/japanese_proc.py`.
> GPT가 투명 대신 체크무늬 배경을 그려 넣어서, 끈 안쪽처럼 갇힌 배경은 무채색 비율로 골라 지웠습니다. (`clear_checker`)

## 요청 2. 테마리 공

```
첨부한 1번 그림은 이 게임에 있는 일본풍 가구이고, 2번은 반려동물 장난감 공이에요. 같은 그림체와 도트 크기로 '테마리 공'을 그려 주세요.
- 일본 전통 실 공: 둥근 공 위에 색실로 수놓은 기하학 무늬 (국화꽃처럼 퍼지는 별 무늬, 띠 무늬)
- 공 하나 크기는 약 12 × 12도트, 아래에 작은 그림자는 그리지 않음
- 한 줄에 칸 하나씩, 색 조합만 다른 세 개: 빨강 바탕 + 흰·금 무늬, 남색 바탕 + 분홍·흰 무늬, 흰 바탕 + 빨강·초록 무늬
- 배경은 진짜 투명 (체크무늬를 그려 넣지 않기)
```

## 요청 3. 이로리 (화덕)

첨부: `art-src/guide/jp-ref.png`

```
첨부한 그림은 이 게임에 있는 일본풍 가구예요. 같은 그림체, 색감, 도트 크기로 '이로리(바닥에 묻힌 화덕)'를 그려 주세요.
- 아이소메트릭: 바닥선과 윗면 모서리가 정확히 가로 2칸에 세로 1칸씩 기울게 (첨부한 코타츠, 좌탁과 똑같은 기울기)
- 바닥 높이의 네모난 나무 테두리 안에 회색 재가 깔려 있고, 가운데 숯불
- 숯불 위에 쇠 받침(삼발이)과 검은 무쇠 주전자
- 크기: 약 67 × 40도트 (코타츠보다 조금 작게, 높이는 주전자까지)
- 한 줄에 같은 칸 크기로 두 칸: 왼쪽은 숯불이 빨갛게 타고 주전자에서 김이 남, 오른쪽은 불이 꺼진 모습 (숯이 검고 김 없음). 나머지는 똑같이
- 배경은 진짜 투명 (체크무늬를 그려 넣지 않기)
```

## 요청 5. 다기 세트

첨부: `art-src/guide/jp-ref.png`, 받은 이로리 그림(`art-src/japanese/gpt-irori.webp`)

```
첨부한 1번 그림은 이 게임에 있는 일본풍 가구이고, 2번은 이로리예요. 같은 그림체, 색감, 도트 크기로 '다기 세트'를 그려 주세요.
- 좌탁 위에 올려 두는 작은 소품: 네모난 나무 쟁반 위에 둥근 찻주전자(옆에 손잡이) 하나와 손잡이 없는 찻잔(유노미) 두 개
- 아이소메트릭: 쟁반 모서리가 정확히 가로 2칸에 세로 1칸씩 기울게 (첨부한 좌탁과 똑같은 기울기), 쟁반 앞쪽이 오른쪽 아래
- 크기: 약 26 × 18도트 (좌탁 위에 올렸을 때 좌탁 윗면의 절반쯤)

- 김은 그리지 않음 (게임에서 따로 올림)
- 배경은 진짜 투명 (체크무늬를 그려 넣지 않기)
```
