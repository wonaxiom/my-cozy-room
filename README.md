# My Cozy Room

데스크톱 옆에 켜두는 나만의 작은 방 게임입니다.

그림과 코드를 만들 때 지킬 기준은 [제작 가이드](GUIDE.md)에 정리되어 있습니다.

## 실행 방법

사이트 주소: https://wonaxiom.github.io/my-cozy-room/

1. 위 주소를 크롬이나 엣지로 엽니다. (파일의 `index.html`을 더블클릭해도 되지만, 그때는 구글 로그인을 쓸 수 없습니다)
2. **위에 띄우기** 버튼을 누르면 작은 창(PiP)이 다른 프로그램 위에 떠 있습니다. 작은 창에서는 마우스를 올렸을 때만 버튼이 나타납니다.
3. 작은 창을 닫으면 원래 페이지로 돌아옵니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 페이지 꾸미기 |
| `data.js` | 색상, 캐릭터 도트, 가구 모양과 가격 |
| `rooms.js` | 방 종류와 처음 놓여 있는 가구 |
| `img/` | 가구·캐릭터 그림 파일 (PNG) |
| `save.js` | 저장/불러오기 (이 컴퓨터) |
| `focus.js` | 집중 타이머와 오늘 할 일 |
| `start.js` | 첫 화면 (로그인, 캐릭터 만들기, 사는 곳) |
| `friends.js` | 친구 (요청, 방 구경, 하트, 방명록, 선물, 채팅) |
| `cloud.js` | 구글 로그인과 계정 저장 (Supabase) |
| `game.js` | 게임 동작 |

## 직접 바꿔보기

- **색 바꾸기:** `data.js`의 `PALETTE`에서 색상 코드를 바꿉니다.
- **캐릭터 바꾸기:** `CHARACTER`의 글자 그림을 고칩니다. 글자 한 칸이 도트 한 칸입니다.
- **가격 바꾸기:** `data.js`의 `FURNITURE`에서 `price` 값을 바꿉니다.
  - `x`가 커지면 오른쪽 아래로, `y`가 커지면 왼쪽 아래로, `z`가 커지면 위로 갑니다.
  - 바닥 크기는 64 x 64입니다.
- **가구 모양 바꾸기:** 가구는 상자(`parts`)를 쌓아서 만듭니다. 색 하나만 정하면 윗면은 밝게, 옆면은 어둡게 자동으로 칠해집니다.

파일을 고친 뒤 브라우저에서 새로고침(F5)하면 바로 반영됩니다.

## 처음 시작하기

1. 사이트에 들어가면 로그인 화면이 나옵니다. **구글로 시작하기**를 누릅니다.
2. 처음 가입하면 시작 설정이 4단계로 나옵니다.
   - **기본:** 성별, 이름, 피부색
   - **얼굴:** 머리 모양(10가지), 머리색(12가지), 눈(기본·큰 눈·실눈·안경·선글라스), 표정(미소·활짝 웃음·무표정·놀람)
   - **옷:** 상의(티셔츠 7색), 하의(바지·반바지·치마 여러 색)
   - **사는 곳:** 고른 지역의 실제 날씨가 창밖에 나옵니다. (위치 권한은 필요 없음)
3. 설정을 마치면 방으로 들어갑니다. 제목은 "이름의 방"으로 바뀝니다.

- 오른쪽 위 **내 정보**를 누르면 캐릭터 그림과 이름, 사는 곳, **고유번호**가 나옵니다.
  - 고유번호는 계정마다 하나씩 서버가 정해 주는 8자리 번호입니다. (예: `K7QP-4M2X`) 나중에 친구를 추가할 때 씁니다.
  - **캐릭터 변경**을 누르면 시작 설정 화면이 다시 열려서 이름, 모습, 옷, 사는 곳을 바꿀 수 있습니다.
- 로그인 기능을 불러오지 못했을 때만 "로그인 없이 하기"가 나옵니다.
- 파일(`index.html`)을 직접 열면 로그인 화면 없이 바로 시작합니다. (만들면서 확인하는 용도)

## 구글 로그인과 저장

- 코인, 보관함, 꾸민 방, 캐릭터, 할 일이 구글 계정에 저장됩니다.
- 처음 로그인하면 지금 컴퓨터의 진행 상황이 계정으로 옮겨집니다.
- 다른 컴퓨터에서 로그인하면 계정에 저장된 진행 상황을 불러옵니다.
- 저장은 15초마다 모아서 하고, 창을 닫거나 다른 창으로 갈 때도 저장합니다.
- 두 컴퓨터에서 동시에 켜 두면 나중에 저장한 쪽으로 덮어써지니, 한 번에 한 곳에서만 켜 두세요.

- **여러 기기에서 쓸 때**: 가구 배치, 구매, 캐릭터 변경처럼 실제로 바꾼 시각(`editedAt`)이 더 최근인 쪽의 데이터를 씁니다. 코인이 쌓이는 저장은 바꾼 것으로 치지 않아서, 켜 두기만 한 기기가 다른 기기에서 바꾼 내용을 덮어쓰지 않습니다. 계정에 올리기 전, 화면으로 돌아올 때, 켜 둔 동안 1분마다 확인하고, 다른 기기에서 바꾼 내용이 있으면 불러온 뒤 알려 줍니다.
- 그림 스타일(ver.하찮 / ver.세밀)은 기기마다 따로 정합니다.

## 친구

화면 왼쪽 위 **친구** 버튼(로그인했을 때)으로 엽니다. 새 요청, 안 읽은 메시지, 새 방명록이 있으면 빨간 숫자가 붙습니다.

- **친구 추가:** 친구의 고유번호를 넣고 **찾기** → **친구 요청**. 상대가 **요청** 탭에서 수락하면 친구가 됩니다.
- **친구 목록:** 캐릭터, 이름, 사는 곳, 상태(접속 중 / 집중 중 / ○분 전 접속)가 보입니다.
- **놀러 가기:** 친구가 지금 있는 방을 그대로 구경합니다. (가구, 캐릭터, 반려동물, 친구 지역 날씨)
  - **하트 남기기:** 친구 방에 하루 한 번. 받은 친구는 10코인을 받습니다.
  - **방명록:** 친구 방에 한마디를 남깁니다. **쓴 사람과 방 주인만** 볼 수 있습니다.
  - 내 캐릭터도 친구 방에 함께 들어가서 돌아다닙니다. (머리 위 노란 표시가 나)
  - 친구가 접속해 있으면 **친구 화면에도 내 캐릭터가 놀러 온 것으로** 보이고, 두 화면의 움직임이 같게 맞춰집니다.
    - 친구 화면에는 "○○님이 놀러 왔어요 / 돌아갔어요" 알림이 뜹니다.
    - 내 화면 아래에는 "○○님이 방에 있어요 / 지금 자리에 없어요"가 표시됩니다.
    - 같은 친구 방에 다른 친구가 놀러 와 있으면 그 친구도 함께 보입니다.
  - 구경하는 동안 내 저장·코인·타이머는 멈추고, **내 방으로**를 누르면 돌아옵니다.
- **대화:** 친구와 1:1 채팅. 보통 1~2초 안에 도착합니다.
- **선물:** 코인(10·50·100)이나 보관함의 물건을 보냅니다.
- **방명록 탭:** 친구들이 내 방에 남긴 글을 모아 봅니다.
- **삭제:** 한 번 누르면 "정말 삭제"로 바뀌고, 다시 누르면 삭제됩니다.

친구에게는 지금 있는 방의 모습, 캐릭터, 이름, 사는 곳, 상태만 보입니다. 할 일 목록, 코인, 보관함은 보이지 않습니다.

## 날씨

- **사는 곳을 고른 경우:** 그 지역의 실제 날씨를 30분마다 받아옵니다. (Open-Meteo 날씨 서비스, 도시 좌표만 사용)
- **고르지 않았거나 날씨를 못 받아온 경우:** 3시간마다 바뀌는 무작위 날씨를 씁니다. 12~2월에는 눈도 내립니다.
- 맑음, 흐림, 비, 눈이 있습니다.
- 흐리거나 비가 오면 창밖 하늘이 회색으로 바뀌고 방도 조금 어두워집니다.
- 지금 날씨는 오른쪽 위 시계 옆에 "부산 비"처럼 표시됩니다. (무작위 날씨이고 맑을 때는 표시하지 않음)
- 사는 곳 목록은 `data.js`의 `CITIES`에서 추가할 수 있습니다.

## 코인 모으기

- 게임을 켜두는 동안 **1분에 2코인**이 모입니다.
- 꺼져 있는 동안에도 **최대 180분치(360코인)**까지 쌓입니다. 다시 열면 모인 코인을 알려줍니다.
- 처음에는 120코인을 가지고 시작합니다.
- 코인 속도와 최대 시간은 `game.js`의 `COINS_PER_MINUTE`, `OFFLINE_MAX_MINUTES`에서 바꿀 수 있습니다.

## 집중 타이머와 오늘 할 일

**집중** 버튼을 누르면 위쪽에 타이머, 아래쪽에 오늘 할 일 목록이 나옵니다.

**집중 타이머**
- 15분, 25분, 50분 중에 고르고 **시작**을 누릅니다. 일시정지하고 이어서 할 수도 있습니다.
- 끝까지 집중하면 **보너스 코인**을 받습니다. (1분당 0.8코인: 15분 12, 25분 20, 50분 40)
- 집중이 끝나면 짧은 알림음과 함께 5분 휴식이 시작됩니다.
- 남은 시간은 화면 위쪽 가운데에 표시되고, 누르면 타이머가 열립니다.
- 방에 책상(책상, 좌탁, 창가 테이블)이 있으면 집중하는 동안 캐릭터가 책상 앞에서 함께 일합니다.

**오늘 할 일**
- 할 일을 적고 끝낸 일에 체크하면 **5코인**을 받습니다. (하루 10개까지)
- 체크를 껐다 켜도 코인은 한 번만 받습니다.
- **끝낸 일 지우기**로 체크한 일을 한꺼번에 정리합니다.

보너스와 휴식 시간은 `focus.js` 맨 위의 숫자에서 바꿀 수 있습니다.

## 상점

**상점** 버튼을 누르면 가구와 소품을 살 수 있습니다. 산 물건은 보관함에 들어갑니다.

- **크리스마스(기간 한정)**: 11월 1일 ~ 1월 31일에만 상점에 '크리스마스' 탭이 보입니다. 트리, 선물 상자 2종, 눈사람 인형, 양말 장식, 리스, 반짝이 전구 줄, 크리스마스 러그, 캔들, 진저브레드 하우스. 산 물건은 기간이 끝나도 계속 쓸 수 있습니다. (`data.js`에서 `category: "xmas"`)
- 구매 버튼을 누르면 "○○을 살까요?" 확인 창이 한 번 뜹니다. 가격과 사고 난 뒤 남는 코인이 함께 나옵니다. **구매**를 눌러야 사지고, **취소**·바깥 부분·Esc 키로 닫을 수 있습니다. (가구·소품·벽지·바닥·방·옷·반려동물 모두)

- 가격은 `data.js`의 `FURNITURE`에서 각 물건의 `price`로 바꿉니다.
- 상점 분류는 `category`로 정합니다. (`furniture` 가구, `prop` 소품)
- **벽지·바닥:** 한 번 사면 모든 방에서 쓸 수 있고, 방마다 따로 골라 적용합니다. 종류와 가격은 `rooms.js`의 `WALLPAPERS`, `FLOORS`에서 바꿉니다.
- **방:** 다다미방과 다락방은 1,000코인, 원형 탑방과 기차 객실은 1,500코인으로 열 수 있습니다. ‹ › 버튼으로 잠긴 방을 구경하다가 바로 열 수도 있습니다. 가격은 `rooms.js`의 `price`에서 바꿉니다.

## 캐릭터 꾸미기와 반려동물

- **장신구**: 야구 모자, 비니, 밀짚모자, 헤어밴드, 리본, 머리핀. 상점 '옷' 탭의 '장신구'에서 사고, 다시 누르면 벗습니다. 시작 설정·캐릭터 변경의 옷 단계에서도 고를 수 있습니다. 종류와 색은 `data.js`의 `ACCESSORIES`에서 바꿉니다.

- **모습과 기본 옷:** 오른쪽 위 **내 정보**에서 바꿉니다. (모두 무료)
- **상점 옷 (상점 → 옷 탭):** 민트 셔츠 80, 줄무늬 티 100, 분홍 후드 100, 검정 니트 120, 노란 우비 150, 초록 반바지 60, 빨간 치마 80
  - 산 옷은 **내 정보 → 옷** 단계에서도 고를 수 있습니다.
- **반려동물 (상점 → 친구 탭):** 치즈 고양이 300, 검은 고양이 300, 하얀 강아지 350
  - 방 안을 돌아다니다가 캐릭터 곁으로 오기도 하고, 가끔 낮잠을 잡니다. 밤에는 함께 잡니다.
  - 클릭하면 하트를 띄우며 반가워합니다.
  - 여러 마리를 데려와도 함께하는 친구는 한 마리이고, **함께하기**/**쉬게 하기**로 바꿉니다.

머리 모양, 색, 눈, 표정, 옷, 반려동물은 `data.js`의 `HAIR_STYLES`, `HAIR_COLORS`, `SKIN_TONES`, `EYES`, `MOUTHS`, `TOPS`, `BOTTOMS`, `PETS`에서 바꾸거나 추가할 수 있습니다.

## 꾸미기 (배치하기)

1. **꾸미기** 버튼을 누르면 아래에 보관함이 나옵니다.
2. 보관함의 물건을 누르면 방의 빈자리에 놓입니다.
3. 방의 물건을 마우스로 끌어서 원하는 자리로 옮깁니다.
   - 초록색: 놓을 수 있는 자리
   - 빨간색: 다른 가구와 겹치는 등 놓을 수 없는 자리 (놓으면 원래 자리로 돌아갑니다)
4. 방의 물건을 누르면 아래에 **방향 돌리기**와 **보관함에 넣기** 버튼이 나옵니다. 방향 돌리기는 누를 때마다 90도씩 돌아가서, 네 번 누르면 처음 방향으로 돌아옵니다. (R 키로도 돌릴 수 있습니다)
   - 방의 물건을 **보관함 위로 끌어다 놓아도** 보관함에 들어갑니다.
5. 다 꾸몄으면 **완료**를 누릅니다.

- 책상, 수납장 같은 가구를 옮기면 위에 올린 물건도 함께 움직입니다.
- 스탠드와 화분은 책상이나 수납장 위에 올릴 수 있습니다.
- 벽에 거는 물건(액자, 선반, 족자, **창문, 벽시계**)은 벽을 따라 옮기거나 다른 벽으로 옮길 수 있습니다.
  - 창문(커튼 창문, 미닫이 창, 둥근 창, 기차 창), 벽시계, 전자 시계는 상점 소품 탭에서 살 수 있습니다.
  - 전자 시계는 24시간 형식(HH:MM)으로 보여주고, 가운데 콜론이 1초마다 깜빡입니다.
  - 원형 탑방의 창문과 시계는 둥근 벽에 붙어 있어서 옮길 수 없습니다.
- **커튼 창문**을 클릭하면 커튼이 닫히고, 다시 누르면 열립니다. 낮에 커튼을 모두 닫으면 방이 조금 어두워집니다.
- 배치는 방마다 따로 저장됩니다.
- 잠자는 가구(침대, 이불, 매트리스)가 없는 방에서는 캐릭터가 밤에도 잠들지 않습니다.

## 그림 스타일 (ver.하찮 / ver.세밀)

화면 오른쪽 위의 **ver.하찮** 버튼을 누르면 **ver.세밀**로 바뀌고, 다시 누르면 돌아옵니다.

- **ver.하찮**: 지금까지의 단순한 도트 그림입니다. (기본)
- **ver.세밀**: 도트 한 칸을 3등분한 단위까지 써서 더 자세하게 그린 그림입니다.
- 고른 스타일은 이 기기에만 기억됩니다. 친구 방에 놀러 가도 내가 고른 스타일로 보입니다.
- 가구는 모두 ver.세밀 그림이 있습니다. (창문·시계는 처음부터 세밀하게 그려서 두 스타일이 같습니다)
- ver.세밀에서는 벽·바닥·가구를 1/3칸 단위로 칠해서 경계가 매끄럽고, 방 전체·가구·캐릭터·반려동물에 진한 외곽선을 넣어 사물이 또렷하게 구분됩니다. (외곽선 색은 `game.js`의 `OUTLINE`)
- 창밖 구름도 ver.세밀에서는 동그란 덩어리를 겹쳐 그리고, 윗부분은 밝게, 아랫부분은 그늘지게 그립니다.
- ver.세밀 캐릭터는 GPT로 만든 남자·여자 도트 그림을 칸 단위로 정리해서 씁니다(`hero-art.js`). 성별에 따라 그림이 바뀝니다. 키는 약 45픽셀(15칸)로, 눈·옷깃·머리결 같은 세부가 보이는 크기입니다. (새 그림에 없는 남자의 바닥 앉기·뒷모습은 예전 그림을 외곽선 1픽셀을 유지한 채 1.25배로 키워 씀)
  - 동작: 서 있기·숨쉬기, 눈 깜빡임, 걷기 8장(오른쪽 그림을 뒤집어 왼쪽), 손 흔들기, 의자에 앉기, 의자에서 타자, 물 주기, 스위치 켜기, 바닥에서 노트북·책·간식, 뒷모습, 잠자기. (여자 그림에 없는 동작은 비슷한 그림으로 대신함)
  - 모든 그림은 머리 가운데와 발 기준으로 맞춰 움직일 때 흔들리지 않습니다.
- 머리 모양 10종은 기본 그림에 머리를 더하거나 다듬어 만들었습니다. 머리색·피부색·상의·하의 색은 고른 색으로 바꿔 칠하고, 눈 모양(큰 눈·실눈)과 입 모양(미소·활짝·무표정·놀람), 안경·선글라스는 그림마다 눈 위치를 찾아 그립니다. 여자는 볼터치가 더해집니다.
- 하의: 남자 그림은 바지·반바지·치마로 바꿔 그리고, 여자 그림은 원래 치마(색만 바뀜)입니다. 줄무늬·후드 같은 상의 모양은 아직 한 가지 그림입니다.
- 반려동물도 ver.세밀에서는 GPT 그림(`pet-art.js`)을 씁니다. 앉기, 걷기 2장, 잠자기. 털 색은 반려동물마다 바꿔 칠합니다.
- 방과 가구는 0.8배로 그려서 캐릭터가 상대적으로 커 보입니다. ver.하찮과 ver.세밀 모두 같은 크기라, 버전을 바꿔도 방 크기가 그대로입니다. (`game.js`의 `WORLD_SCALE`)
- **가구 쓰기**: 캐릭터가 돌아다니다가 가끔 방에 놓인 가구로 걸어가서 씁니다. (`game.js`의 `INTERACT`)
  - 책장·벽 선반: 앞에 앉아 책 읽기 / 좌탁·창가 테이블·서랍장: 옆에 앉아 간식 / 방석: 위에 앉아 책이나 간식
  - 창문·망원경·지구본: 앞에 서서 구경(뒷모습) / 화분: 물 주기 / 스탠드·종이 등: 저녁에 켜고 아침에 끄기
  - 의자·보조 의자·안락의자·객실 좌석: 앉아서 쉬기 / 집중할 때 책상 가까이에 의자가 있으면 의자에 앉아 타자
- **조명**: 조명은 하나씩 따로 켜고 끕니다. 누른 조명만 바뀌고, 상태는 방 배치와 함께 저장됩니다. 캐릭터는 저녁에 한 번 켜러, 아침에 한 번 끄러 가고, 그 시간대에 직접 켜거나 끈 조명은 건드리지 않습니다.
  - 캐릭터를 누르거나, 잘 시간·집중 시간이 되면 하던 일을 멈춥니다. (ver.하찮은 책 읽기·간식 때 머리 위에 작은 그림)
- 반려동물은 ver.세밀에서 글자 그림을 3배로 키워 모서리를 다듬고 음영과 외곽선을 넣어 그립니다.
- 세밀한 그림은 `data.js`에서 가구마다 `detail` 목록으로 넣습니다. `detail`이 없는 가구는 두 스타일 모두 `parts`로 그립니다.
- `book`, `flatBook`, `smallPlant`, `jarCandle`, `slantLeg` 같은 도우미로 책, 화분, 초, 비스듬한 다리를 쉽게 만들 수 있습니다.
- 가는 줄은 비스듬한 면에서 점선처럼 끊겨 보이니, 옆면의 가로줄은 높이 2/3 이상, 윗면의 줄무늬는 폭 1 이상으로 그립니다.

## 방 종류

‹ › 버튼으로 방을 바꿀 수 있고, 마지막으로 고른 방이 저장됩니다. 원룸은 처음부터 열려 있고, 나머지 방은 상점에서 열 수 있습니다.

| 방 | 모양 | 가격 | 특징 |
|---|---|---|---|
| 원룸 | 네모난 방 | 기본 | 나무 바닥, 커튼 창문, 벽시계 (매트리스와 스탠드로 시작) |
| 다다미방 | 네모난 방 | 1,000 | 다다미 바닥, 나무 기둥, 미닫이 창 |
| 다락방 | 삼각 지붕 | 1,000 | 비스듬한 지붕, 둥근 창 |
| 원형 탑방 | 둥근 방 | 1,500 | 돌 벽, 둥근 바닥 (둥근 벽에는 벽 소품을 걸 수 없음) |
| 기차 객실 | 길쭉한 방 | 1,500 | 창밖 풍경이 지나감, 레일과 바퀴, 객실 문 |

### 방 추가하기

`rooms.js`의 `ROOMS` 목록에 방을 하나 더 적으면 됩니다. 기존 방 하나를 복사한 뒤 바꾸는 것이 가장 쉽습니다.

- `shape`: 방 모양 (`box` 네모난 방, `attic` 다락방, `round` 원형 탑방, `train` 기차 객실)
- `width`, `depth`: 바닥 크기 (기본 64 x 64), `offset`: 화면에서 방 위치 조정
- `colors`: 이 방에서만 바꿀 색
- `price`: 방을 여는 가격 (0이면 처음부터 열림)
- `wallpaper`, `floor`: 기본 벽지와 바닥 (`WALLPAPERS`, `FLOORS`의 id)
- `window`: 창문 스타일
- 잠자는 가구(`data.js`에서 `sleep`이 있는 가구)를 하나 넣어 주세요.
- `layout`: 처음 시작할 때 놓여 있는 가구 (처음 한 번만 쓰이고, 이후에는 직접 꾸민 배치가 저장됩니다)

## 그림 파일 넣기

가구와 캐릭터를 직접 그린 그림(PNG)으로 바꿀 수 있습니다. 그림이 없는 가구는 지금처럼 상자로 그려지니, 하나씩 천천히 바꿔도 됩니다.

### 가구

1. 배경이 투명한 PNG를 `img` 폴더에 넣습니다.
2. `data.js`의 `FURNITURE`에서 해당 가구에 `image`와 `size`를 추가합니다.

```js
plant: {
  name: "화분",
  image: "img/plant.png",
  size: [8, 8, 14],   // [가로, 세로, 높이]
  ...
},
```

- 그림의 가로 크기를 `size`의 **가로 + 세로**로 맞추면 바닥에 딱 맞습니다. (화분은 8 + 8 = 16도트)
- 그림의 맨 아래가 가구 바닥의 가장 앞 모서리에 놓입니다.
- 위치가 살짝 어긋나면 `offset: [좌우, 위아래]`로 도트 단위 조정을 합니다.
- 조명 가구는 꺼졌을 때 그림을 `imageOff`로 따로 지정할 수 있습니다.
- `img/plant.png`가 예시 그림입니다. (지금 화분은 그림 파일 대신 도트 상자로 그려서 ver.하찮/ver.세밀이 나뉩니다. 그림 파일을 쓰면 두 스타일 모두 같은 그림이 나옵니다)

### 캐릭터

1. 동작 그림 5개(가만히, 눈 깜빡임, 걷기1, 걷기2, 잠자기)를 같은 크기로 가로로 나란히 붙인 PNG 한 장을 만듭니다.
2. `data.js`의 `CHARACTER_SHEET`를 `null`에서 아래처럼 바꿉니다.

```js
const CHARACTER_SHEET = {
  image: "img/hero.png",
  frameWidth: 16,     // 동작 하나의 가로 크기
  frameHeight: 24,    // 동작 하나의 세로 크기
  frames: { idle: 0, blink: 1, walk1: 2, walk2: 3, sleep: 4 },
};
```

- 캐릭터는 각 칸의 가로 가운데, 맨 아래가 발 위치입니다.
- 오른쪽을 보는 모습으로 그리면, 왼쪽으로 걸을 때는 자동으로 뒤집힙니다.

### 그릴 때 기준

- 바닥선은 **가로 2칸에 세로 1칸**씩 내려가게 그립니다.
- 빛은 **왼쪽 위**에서 들어옵니다. 윗면은 밝게, 왼쪽 면은 중간, 오른쪽 면은 어둡게 칠합니다.
- 크기 기준: 캐릭터 키 약 14도트, 벽 높이 44도트입니다. (ver.하찮 기준)
- ver.세밀 그림의 크기와 규칙은 [제작 가이드](GUIDE.md#2-그림-제작-가이드)를 따릅니다.

## 업데이트할 때

`index.html`에서 파일 이름 뒤의 `?v=` 번호를 새 번호로 바꿔 주세요. (예: `style.css?v=20261115-2` → `?v=20261120-1`)
번호가 바뀌어야 브라우저가 옛 파일 대신 새 파일을 받습니다.

## 테스트용 주소

- `?month=12`: 그 달처럼 보입니다. (기간 한정 탭 확인용, 1~12)

주소 끝에 붙여서 확인할 때 씁니다. 여러 개를 함께 쓸 때는 `?hour=21&room=tatami`처럼 `&`로 잇습니다.

| 붙이는 값 | 하는 일 |
|---|---|
| `?hour=21` | 밤 9시처럼 보이게 하기 |
| `?room=attic` | 다락방으로 시작하기 |
| `?coins=1000` | 코인을 1000으로 바꾸기 (저장됨) |
| `?slot=a` | 저장 칸을 따로 쓰기 (한 브라우저에서 여러 사람 시험) |
| `?weather=rain` | 날씨 고정하기 (`clear`, `cloudy`, `rain`, `snow`) |

- `?hour=14` 낮
- `?hour=18` 저녁
- `?hour=21` 밤
- `?hour=2` 잠자는 시간 (23시~7시에는 침대에서 잡니다)
