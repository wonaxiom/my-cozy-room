개인정보처리방침

시행일: 2026년 11월 16일

My Cozy Room(이하 "서비스")은 개인이 운영하는 무료 게임입니다. 서비스는 게임을 제공하는 데 필요한 최소한의 정보만 수집하며, 아래와 같이 처리합니다.

1. 수집하는 정보

구분내용
구글 로그인 정보계정 식별자, 이메일 주소, 구글 프로필 이름
게임 정보캐릭터 이름과 모습, 코인, 방 꾸미기, 산 물건, 할 일 목록, 집중 타이머 기록, 고른 사는 곳(도시), 고유번호
친구 기능 정보친구 관계, 방명록 글, 채팅 메시지, 하트, 선물 기록

정확한 위치 정보, 휴대폰 번호, 결제 정보는 수집하지 않습니다.

2. 이용 목적

  • 로그인과 계정 구분
  • 여러 기기에서 게임 진행 상황을 이어서 할 수 있도록 저장
  • 친구 추가, 친구 방 구경, 방명록, 채팅 등 친구 기능 제공
  • 고른 도시의 날씨를 게임 화면에 보여주기

3. 공개 범위

  • 친구에게는 지금 있는 방의 모습, 캐릭터, 이름, 사는 곳(도시), 접속 상태만 보입니다.
  • 할 일 목록, 코인, 보관함은 다른 사람에게 보이지 않습니다.
  • 방명록 글은 쓴 사람과 방 주인만, 채팅 메시지는 보낸 사람과 받은 사람만 볼 수 있습니다.
  • 친구가 아닌 사람은 고유번호를 정확히 입력했을 때 이름만 확인할 수 있습니다.

4. 보관 위치와 외부 서비스

  • Supabase(서울 지역 서버): 로그인 정보와 게임·친구 기능 정보를 저장합니다.
  • Google: 구글 계정으로 로그인할 때 사용합니다.
  • Open-Meteo: 날씨를 받아올 때 고른 도시의 대략적인 좌표만 보냅니다. 계정 정보는 보내지 않습니다.
  • GitHub Pages: 게임 화면 파일을 제공합니다.
  • 게임 진행 상황의 사본은 이용자 브라우저의 저장소(localStorage)에도 저장됩니다.

수집한 정보를 판매하거나 광고에 쓰지 않으며, 위 목적 외의 제3자에게 제공하지 않습니다.

5. 보관 기간과 삭제

정보는 계정이 있는 동안 보관합니다. 계정과 모든 데이터의 삭제를 원하면 아래 문의처로 요청해 주세요. 확인 후 지체 없이 삭제합니다. 브라우저에 남은 사본은 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

6. 문의처

GitHub 이슈 페이지에 남겨 주시거나, 구글 로그인 동의 화면에 표시된 지원 이메일로 연락해 주세요.
