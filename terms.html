서비스 약관

시행일: 2026년 11월 16일

1. 서비스

My Cozy Room(이하 "서비스")은 개인이 운영하는 무료 게임입니다. 구글 계정으로 로그인해 이용할 수 있습니다.

2. 이용자가 지켜야 할 것

  • 방명록, 채팅, 이름에 욕설, 괴롭힘, 불쾌감을 주는 내용, 광고를 쓰지 않습니다.
  • 다른 사람의 계정을 쓰거나, 서비스의 정상적인 운영을 방해하지 않습니다.
  • 코인 등 게임 데이터를 비정상적인 방법으로 바꾸지 않습니다.

위 내용을 어기면 친구 기능 이용이 제한되거나 계정이 삭제될 수 있습니다.

3. 게임 데이터

코인과 게임 속 물건은 게임 안에서만 쓰이며, 현금이나 다른 재화로 바꿀 수 없습니다. 서비스는 데이터를 안전하게 보관하려고 노력하지만, 오류나 서비스 중단으로 데이터가 사라질 수 있습니다.

4. 서비스 변경과 중단

서비스는 개인 프로젝트로, 기능이 바뀌거나 미리 알리지 않고 중단될 수 있습니다.

5. 계정 삭제

계정 삭제를 원하면 GitHub 이슈 페이지 또는 구글 로그인 동의 화면의 지원 이메일로 요청해 주세요.

6. 개인정보

개인정보 처리는 개인정보처리방침을 따릅니다.
